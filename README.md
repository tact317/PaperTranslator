# PeperTranslator

**英語論文を日本語で読み、翻訳結果を確認しながら学習できる、デスクトップ向け論文リーダーです。** Reader、論文ライブラリ、翻訳、学習クイズ、語彙・日本語版の閲覧を一つの画面にまとめています。

> **現在の提供状況（2026-11-13）**：開発者のWindows環境で起動・PDF翻訳を確認済み。GitHubにはソースとローカル検証候補のビルド手順を保存しています。**一般配布版・他PCでの動作保証はまだありません。** リリース用インストーラーが完成したという意味ではありません。

## できること

- **Reader**：英語論文PDFを読み込み、本文とページを確認する。
- **翻訳**：英語論文の日本語訳を作成・確認する。翻訳実行にはローカルの翻訳エンジン・モデルなど、利用環境ごとの設定が必要です。
- **学習支援**：論文に基づくクイズ、語彙、ライブラリなどの機能を利用する。
- **品質表示**：翻訳の品質チェック結果を参考指標として確認する。
- **モバイルPWA**：`mobile-pwa/` に別系統のオフライン対応版があります。Windows版と機能が完全一致するわけではありません。

## 品質表示の扱い

**品質表示は、論文やページごとの翻訳結果を見直すための目安であり、合否判定や翻訳品質の保証ではありません。** 原文の構造・数式・図表・単位や文章の複雑さにより、結果にはばらつきが生じます。品質チェックで警告や低評価が出ても、それだけでアプリ全体の不具合・翻訳失敗とは判定しません。逆に高評価でも、内容の正確性を保証しません。

研究用途では、重要な数値・単位・数式・図表・引用は原文と照合してください。品質表示と翻訳アルゴリズムは、アプリの提供後も継続して改善する方針です。**現段階では、すべての論文で満点を得ることを完成条件としていません。**

## テスト

バックエンドの採点・翻訳品質ロジックには回帰テストがあります。リポジトリのルートで実行します（`pytest` が必要）。

```
python -m pytest backend/tests -q
```

2026-11-13時点で389件が合格しています（Python 3.14、Ollamaはテスト内でダミーに置換）。`evaluation/` はテストが参照する回帰コーパスで、大半は自作の合成文、一部は出典を明記した公開論文からの短い引用です。

## 開発時の注意

- 既存インストール版と検証候補はポート`8000`/`31337`を共有する可能性があります。同時起動しないでください。
- ユーザーのLibrary、PDF、認証情報、`.env`、モデルなどの個人データをGit管理や配布物に含めないでください。
- `packaging/legacy-v1728/`内の旧インストーラーは参照用です。既存インストールを消去する可能性があるため**実行しないでください**。
- 本リポジトリの公開・再配布にあたっては、使用するソフトウェアとモデルのライセンスを確認してください。ライセンスの未記載は利用・再配布許可を意味しません。
